# Akatsuki Technical Spikes

This directory contains disposable Phase 0.1 investigation artifacts. Nothing here is production application code, a supported package, or a dependency baseline.

- `backend-runtime/`: equivalent Fastify and NestJS sketches.
- `orm-comparison/`: equivalent Drizzle and Prisma persistence sketches.

No dependencies were installed and no sample was executed. The sketches intentionally use incomplete imports and placeholder ports to evaluate architectural shape rather than framework correctness. Findings are recorded in `docs/spikes/phase-0-1-results.md`.
